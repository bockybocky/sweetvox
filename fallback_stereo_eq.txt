# 安全版（純 EQ，不拆 MID/SIDE）
# 用途：萬一 APO 對 Copy 那四行有意見、或想 A/B 比較「有拆中側」的差別時用。

Filter 3: ON PK Fc 3000 Hz Gain 2.5 dB Q 0.9
Filter 4: ON PK Fc 7500 Hz Gain -1.5 dB Q 2.0
Filter 5: ON HS Fc 10000 Hz Gain -1.5 dB
